# The Comment Above the Code

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-7c3aed)](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026)
[![license: MIT](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![entry: one line](https://img.shields.io/badge/entry-one%20line%20%E2%80%A2%2089%20chars-blue)](main.ts)

One funny, painfully honest line imagining the comment a developer left above
fragile production code — a make.fun bounty entry.

> `// The discount is applied twice. I know. Fixing it would break twelve years of invoices.`

The program writes that single line (89 characters) to `/output/entry.txt`.

- Bounty: [The Comment Above the Code](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026)
- Run: `node main.ts` (Node 22+; `MAKEFUN_OUTPUT_DIR` overrides `/output` for local runs)
- How the line was picked: 20 candidates, shortlist of 6, pairwise two-way arena
  against the judge's criteria, then the winner beaten against the 3-line gold set.
